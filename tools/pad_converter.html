PAD コード変換器（ブラウザ版）

録画 JSON を Power Automate Desktop の Robin コードに変換します。 インストール不要で、このページ 1 つで完結します。通信は一切しません。

1. 録画 JSON
ここにドラッグ＆ドロップ、またはファイルを選択
録画 JSON・バッチ定義 JSON のほか、この変換器で作った Robin（.txt）も読める。 Robin の末尾に埋め込まれた元のバッチ定義を取り出す。埋め込みの無い古い Robin は、中身を読み解いて組み立てる。
1-2. 操作の振り分け

録画された操作を 4 つの箱に振り分けます。 推測で選んであるので、違うところだけ直してください。 キー入力の記録など、変換に使わないものは隠しています。

ファイルダウンロードの保存名には {{列名}} で明細の値を、@ID@（ID 列） @KEY@（業務キー）@STAMP@（日時）を差し込めます。 例: {{プロジェクト番号}}_XXPO_検収状況一覧_{{要求ID}}。 空にすると、下で決めたエビデンスのファイル名と同じ書式になります。 拡張子はそのまま残るので付けません。

結果CSVに記録の「キー」に画面の文字（例: 要求IDは）を 入れると、その直後を記録します。ポップアップの中も探します。 「数字だけ」なら直後の数字のまとまりだけを取ります。 キーは画面に 1 回しか出ない形にしてください（同じ文字が複数あると最初のものを取ります）。

setup=最初に 1 回だけ　 loop=1 件ごとに繰り返す　 loop+復帰=繰り返し、かつ失敗時に戻る手順にも使う　 teardown=最後に 1 回　 使わない=変換に含めない

2. 実行環境（PAD を動かす PC）のパス

ここに書いた値は生成物にそのまま埋め込まれます。変換した PC のパスではなく、 PAD を動かす PC のパスを入れてください。

.csv のほか、Excel の .xlsx も使えます。.xlsx は「明細」シートの 1 行目を列名として読み、最後に結果を見る用の Excel（pad_result_日時.xlsx）も作ります。 明細の入れ物は、変換したあと「明細テンプレート（Excel）を保存」で作れます。
下の「明細ファイル」を選べば先頭列が自動で入ります
フォルダだけを書く。ファイル名はブラウザーに合わせて msedgedriver.exe / chromedriver.exe になる
3. オプション
最初に開く URL。ログイン前の入り口の URL（ブックマークしている URL）を 入れてください。録画や読み込んだバッチ定義の URL が入ります。ここで直すとバッチ定義に保存されます。
@ID@ / @KEY@ / @STAMP@ を差し込める
登録側が記録した要求 ID などを使うとき。結果は pad_result_2.csv へ
ログや結果CSVと同じ場所にしないこと
取得・更新が順調なら外してよい。バージョンが合わないときと失敗したときは、外していても出る
どちらも既定はオン。社内ではプロキシ、テレワークでは直結のように 場所で切り替わる PC でも、書き換えずに動く。
上の「明細ファイル (--details)」は実行環境のパスを書くだけで、中身は読めません。 列名を確かめたい場合は、変換するこの PC にある同じ CSV をここで選びます。
運用スイッチ
件 ※ まず 1 件で試し、正常に動くのを確かめてから増やす
横 × 縦 （既定 1250 × 900。録画 JSON を読むと録画時の大きさが入る）
※ 複数の PC に配布する場合は、一番小さい画面に収まる値にそろえる。 エビデンスはページ全体を撮るので、縦を小さめにしても写る範囲は切れない。
サイトの設定（バッチ定義に保存）
サイトに合わせる設定。バッチ定義に保存され、次に読み込んだときに戻る。 既定は「画面が落ち着くまで待つ」だけオフで、ほかはオン。合わないサイトだけ変える。
最大 秒 画面の切り替わりが遅いサイトは増やす
自動送信の予約・通信・読み込みが終わってから次の操作に進む。既定はオフ
上の「明細ファイル（列名の確認用）」を選んだときに働く

「保存」はブラウザーの既定のダウンロードフォルダーに書き出します。 共通 JavaScript はコピーのみです（スクリプト単体のファイルはウイルス対策に ブロックされるため）。
